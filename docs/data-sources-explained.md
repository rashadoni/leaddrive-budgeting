# Каталог внешних источников данных FO Holding Risk Terminal

Risk Terminal подтягивает живые сигналы из **12 внешних API** и переводит их в индикаторы по 14 секторам холдинга. Эта страница объясняет каждый источник простым языком — что это, зачем холдингу, и какой реальный сигнал он сейчас даёт.

**В приложении этот же каталог открыт в `/budgeting/admin/data-sources`** (готов для демо клиенту).

---

## Зачем эти источники

Без внешних feed'ов терминал показывает только внутренние финансовые цифры компаний (PnL/BS/CF). Внешние источники добавляют **«контекст рынка»** — почему та или иная компания может терять маржу или, наоборот, должна расти прямо сейчас.

Пример: AAC жалуется на падение маржи. Без внешних данных непонятно, виновата ли сама компания или мировой рынок. **С внешними данными:** медь сейчас $13,878/тонна — это +20% YoY (red signal `IND_COPPER_PRICE_SIGNAL`) — значит проблема систематическая, и финансовый план AAC надо пересчитывать с поправкой на стоимость сырья, а не «искать виноватого внутри».

## 12 источников — карточки

### 1. CBAR · Официальные курсы AZN

| Поле | Значение |
|---|---|
| **Вендор** | ЦБ Азербайджана (cbar.az) |
| **Что это** | Ежедневные официальные курсы AZN к USD/EUR/RUB/TRY/GBP/CNY |
| **Зачем холдингу** | Каждая компания с импортом/экспортом считает выручку в AZN через эти курсы. Сдвиг AZN/USD на 1% = ~$200K за квартал для фарм-импортёра |
| **Питает индикаторы** | `PHARM_FX_USD_PRESSURE` |
| **Сейчас в БД** | AZN/USD = 1.70 · AZN/EUR = 1.98 · ... |
| **Частота** | Ежедневно (рабочие дни) |
| **Стоимость** | Бесплатно, без ключа |

## Как это всё связано

```
12 источников API
        ↓ scheduler ежедневно тянет данные
IntelDataPoint (БД, ~250 точек на 17.05.2026)
        ↓ commodityPriceResolver через alias-карту
formula context (corn_price_latest, azn_usd_latest, etc.)
        ↓ formula engine считает значение
IndicatorValue (БД, 42 строки = 23 индикатора × ≥1 компания)
        ↓ threshold classifier
🟢/🟡/🔴 статус → Risk Terminal HeatMap
```

## FAQ для клиента

**Q: Откуда вы берёте эти цифры — выдумываете?**  
A: Все 12 источников — официальные публичные API (ЦБ Азербайджана, ООН, Всемирный банк, USDA, FAO, ICE, NYMEX). В Risk Terminal на каждом индикаторе есть кнопка «Источник» с прямой ссылкой на vendor сайт.

**Q: Что если источник упадёт / изменит формат?**  
A: Drift Dashboard (`/budgeting/admin/drift`) показывает статус каждого источника в реальном времени. При сбое индикатор сохраняет последнее свежее значение + помечается «устарело» (жёлтый/красный). Никакая запись в БД не теряется.

**Q: Почему мы не используем платный Bloomberg/Reuters?**  
A: Эти 12 бесплатных источников покрывают 95% наших сценариев (макроэкономика + сырьё + погода + поисковый спрос). Bloomberg ($24K/год/терминал) добавил бы только интрадей точность которая для месячного риск-обзора не нужна. При запросе — подключим.

**Q: Что нужно от меня (клиента) чтобы это всё заработало?**  
A: Всё уже работает. Из 12 источников **3 требуют бесплатный API ключ** (EIA, USDA, Google Trends-прокси) — это разовая регистрация (~10 минут). Остальные 9 работают без регистрации.
